# Progetto-E-Bike-scuola-
Questo è un progetto scolastico fatto come compito fatto in online gbd in c++.

Il file contiene un app sperimentale per un noleggiatore di bici elettriche nella tua città, all’inizio ti vengono chieste le tue coordinate, ovviamente non satellitari ma solo grazie a due numeri cioè la X e la Y, il codice usa le tue coordinate per trovare le bici più vicine.

Per selezionare le bici ci sono degli ID in più all’inizio ti deve chiedere i chilometri che vuoi percorrere così che se una bici non ha abbastanza batteria per poterla prendere non puoi selezionarla. 

Infine se tutti i requisiti sono accettati puoi selezionarla e ti dà anche un costo rispetto ai minuti trascorsi in bici.
